## 3. 采集模块（爬虫）验收

### 3.1 平台与字段

| 检查项 | 淘宝/天猫 | 京东 | 1688 | 结果 |
|---|---|---|---|---|
| `platform` / `product_id` / `url` / `title` / `price` / `main_image_url` / `crawled_at` / `listed` | 必有 | 必有 | 必有 | ☐ |
| `shop_id`（不得用店名代替；缺失标 `shop_id_missing`） | 列表页可得 | 列表页可得 | 多数需详情补；缺失可标 | ☐ |
| `shop_name` / `shop_type`(归一) / `shop_label_raw` | 天猫/C店可辨 | 自营/POP | 实力商家等 | ☐ |
| `sales_raw` + `sales`(下限) | 列表页模糊值 | 常缺 → 销量缺失 | 成交件数 | ☐ |
| `comments_raw` + `comments` | 仅文字过线/need_vision 才抓详情 | 列表页一般有 | 详情补；可缺 | ☐ |
| `search_keyword` / `ip_code` | 有 | 有 | 有 | ☐ |
| product_id 解析失败 → 丢弃并记入运行日志错误 | 有 | 有 | 有 | ☐ |

### 3.2 登录与节流

- [ ] 每平台独立持久化浏览器 profile（不导出 cookie）
- [ ] 启动先检测登录；失效 → **停止该平台** + 触发报警路径，不强抓
- [ ] 遵守 `crawl.rate_limit` 与 `max_items_per_keyword`
- [ ] 本轮 `pdd.enabled=false`，不得误开拼多多

### 3.3 详情策略

- [ ] **C4**：淘宝文字分 <35 且非 need_vision → 不抓详情（日志可证）
- [ ] **B7**：京东店铺合计在门槛×[0.6,1.0) → 触发详情补抓；低于下沿不触发
