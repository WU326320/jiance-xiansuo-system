## 2. 用户目标与应保持的行为

用户原需求：“创建任务以后就立即开始，设定结束时间就行了”。

沿用现有执行链：`workbench → TaskService → PipelineRunner → crawler → backend/export`。

- 新建表单填写未来的结束时间 `ends_at`，点击“创建并运行”后立即进入执行流程。
- 提前采完可以正常结束，不需要等待截止时间。
- 到达结束时间，停止采集和详情补抓；保留本次已采数据，继续入库、判定、导出与完成通知。
- 截止约束针对采集阶段；报表和通知允许稍晚完成。
- 保留历史 `scheduled_at` 预约任务兼容性。
- 同一时间只运行一个任务；立即创建不应破坏现有互斥执行机制。
