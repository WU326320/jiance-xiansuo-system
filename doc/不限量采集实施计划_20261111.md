# 不限量逐页采集实施计划

**目标：** 按用户要求逐页采集及逐条补采，不以页数、商品数、关键词数、每日数量、补采数量或默认整批时长截断。

**实现：** 真实分页状态决定当前关键词是否结束；未知空页、重复页及风控保留未完成进度。旧数量配置和参数保留解析兼容，但不再用于停止采集。仅用户明确提供的截止时间继续生效，请求间隔及单次请求错误处理保留。

**技术栈：** 沿用 Python、Playwright、pytest 和现有工作台，不新增依赖或更换服务端口。

**需求依据：** 用户本轮明确要求“一页一页的往后翻往后采集就好了，包括你的补采以及其他，我从来没有设定过上限”。

## 验证重点

1. 未配置截止时间时，旧页数、商品数、关键词数、分段和每日配额不能终止任务。
2. 详情和店名补采覆盖全部缺失候选，真实销量0有效，评论数不能充当销量。
3. 明确末页或明确空结果才能完成当前关键词；缺控件、重复列表和解析异常不算完成。
4. 每页数据和断点保留；异常不丢弃已采数据。
5. 用户明确截止后不新增搜索，补采不被父进程默认时限终止。
