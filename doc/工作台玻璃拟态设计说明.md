# 工作台玻璃拟态候选版

状态：独立原型，等待视觉与操作确认；正式前端未进入实施。

## 查看方式

用 Microsoft Edge 打开 [玻璃版原型](../prototype/workbench-glass.html)。顶部可跳转 [iOS 版](../prototype/workbench-ios.html) 对比，也可勾选“降低透明度”体验实色回退。HTML 直接打开，无服务、端口或新增依赖。

## 已确认方向

浅色磨砂玻璃加冰蓝灰。面向日常查看店铺、证据、金额与任务的工作人员，把玻璃材质放在导航与操作层，证据和列表使用高不透明度背景，保持阅读效率。原有导航分组与操作流程见 [完整重构方案](工作台重构设计方案.md)。

### 视觉规范

| 项目 | 本版选择 |
|---|---|
| 基底 | 冰蓝灰 `#eaf0f7`，叠加低饱和冰蓝、灰紫、青灰柔光 |
| 文字 | 深蓝灰 `#20334b`，辅助 `#56677b`；正文16px、辅助14px、页面标题32px |
| 操作 | 主色 `#205ec8`，明确的蓝色主按钮；风险状态沿用文字加色彩表达 |
| 导航材质 | 57%白色面板、26px背景模糊、白色边缘高光、浅蓝灰投影；悬浮侧栏与工具栏 |
| 内容材质 | 列表、商品证据、表单正文使用白色背景；辅助面板使用高不透明度乳白色 |
| 分段切换 | 玻璃选中块，260ms平滑移动；原生按钮继续响应点击与Enter/Space，新增方向键/Home/End切换 |
| 弹层 | 背景9px柔化、22–27px圆角、头尾磨砂、正文白底，220ms短淡入 |
| 回退 | 手动降低透明度、系统减少透明度、无背景模糊支持时使用实色；减少动效时停止滑动及淡入 |

## 视觉精修记录

优化对象为当前玻璃原型；保留原有内容、模拟业务状态和操作路径。变更限于 `workbench-glass.css`、原型顶部比较链接、独立对比页及验收材料。业务脚本、正式前端、数据库没有修改。

### 问题与优先级

1. 首屏纵向层级过长：标签、筛选、结果提示连续留白，使主要列表下移。统一压缩容器间距，保留输入控件高度和正文可读性。
2. 手机卡片重复显示店铺/IP、平台、风险、操作标签，选择框独占一行。将选择框放在右上角，保留店铺/IP、平台徽章、风险徽章、金额及操作，删除仅用于重复解释的可视标签；原有语义与输入标签保留。
3. 多层样式叠加使部分导航图标仍为彩色块，材质不统一。精确限定玻璃导航图标样式，使所有模块使用同一淡蓝玻璃底。
4. 金额与操作入口缺少稳定视觉重心。金额统一等宽数字，复核入口统一为浅蓝按钮，表格列内对齐与间距一致。
5. 证据详情字段散列。将单价、销量和金额放入统一浅底数据区，与商品标题、规则展开入口分层；人工复核区保留明确的区域背景。

## 透光与厚度材质调整

本轮保持页面结构、尺寸、内容和交互脚本不变，仅调整玻璃原型材质与验证材料。

- 原面板白色覆盖较重，背景只有均匀柔光，玻璃更接近浅色实心面板。现将主要导航玻璃基底白色覆盖由67%降到28%，叠加局部弱反光，背景加入低饱和弧形色带。色带在面板内外连续，可直观看到透光关系。
- 侧栏模糊由26px减为14px，顶部工具栏由24px减为12px；让背景保留轮廓和颜色，而不是全部化为均匀雾面。
- 上沿、左沿为细亮边，下沿采用更淡的蓝灰边与1–2px内阴影，配合近距离接触阴影与远距离柔投影，形成厚度；减少四边同强度的纯白描边。
- 分段选中块和次按钮使用一致的上亮下暗关系；标题、筛选面板与任务概况的透光量按阅读负荷分级。
- 弹层头尾透出背景色，正文保持高不透明度；遮罩模糊从9px降为4px，弹层自身16px磨砂，背景仍能辨认。
- 降低透明度、系统减少透明度及不支持背景模糊时，侧栏、工具栏、内容面板和弹层均回退实色；不改变控件位置。

这属于CSS对材质的视觉模拟，未实现物理光学折射或真实场景光照。玻璃响应来自实际背景采样和分层阴影，没有声称使用原生系统玻璃渲染器。

验收新增蓝色/淡紫背景下的像素响应检查，确认侧栏确实透出背景色；同时检查模糊参数和实色回退。总计19组，继续覆盖11个视图、四种宽度、原有交互与前后对比页。实际运行结果以 [验收JSON](工作台玻璃原型验收结果.json) 为准。

对比页新增“本轮材质对比”，左侧为本次修改前的 `glass-material-before.png`，右侧为最新实拍，使用同一数据和1440px视口。正式前端和共享交互脚本没有修改。
