# 单表导出实施计划

目标：导出一个“链接明细”sheet，仅含平台、IP、店铺名、标题、缩略图、商品链接、单价、销量、评论、总金额十列。

沿用 Python、openpyxl、Pillow 和只读视图。商品金额保持后端估算值，导出只对商品金额求和，使用十进制运算；缺失金额不冒充零。销量、评论保留原文。旧 Excel 复核模板仍可导入，新十列表不提供复核回写列。

分组优先使用后端店铺键及店铺 ID，同名不同店和不同平台组不合并；淘宝/天猫沿用后端平台组。组内相同 IP 连续排列，多条记录整行同底色，组末添加“同IP小计”；表尾添加“总计”，不重复累计小计。空店铺不强行合并。仅一条记录的组不插小计。空结果只输出表头。

采用保留完整商品行并增加小计行的方式，便于逐条查阅和看到每组金额；不合并商品金额单元格，避免遮蔽单条金额。汇总行明确标识，筛选覆盖商品和小计，尾部总计不进入筛选。

涉及文件：export/lead_excel/{columns,db,api,workbook}.py；backend/pipeline/views.py；视图字段迁移；导出、后端任务隔离与工作台接口测试；export/README.md。
